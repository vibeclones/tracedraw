    Цветовые стили

    Цветовой стиль это именованный цвет, который используют объекты рисунка. Измените стиль, и все объекты с заливкой этим цветом тоже изменятся: так цвета дизайна остаются согласованными, и можно быстро попробовать другие цветовые схемы. Стили перечислены на панели Стили цвета; откройте её через Окно > Панели.

    Создание цветовых стилей#

    • Создать из выделения добавляет стиль для каждого цвета заливки выделенных объектов, который ещё не является стилем.
    • Новый стиль цвета добавляет стиль из текущего цвета панели Цвет.

    Использование и правка стилей#

    Каждый стиль показывает свой цвет, имя и три кнопки:

    • щёлкните цвет, чтобы изменить его: объекты с заливкой этим цветом последуют за ним;
    • щёлкните имя, чтобы переименовать стиль;
    • Заливка заливает выделенное стилем, Абрис окрашивает его абрис;
    • x удаляет стиль (объекты сохраняют свой цвет).

    Гармонии#

    Редактор гармоний создаёт набор сочетающихся стилей на основе Основной цвет:

    1. Выберите Основной цвет.
    2. Щёлкните гармонию: Аналоговая, Дополнительная, Расщеплённая дополнительная, Триада, Тетрада или Монохромная.

    Цвета гармонии добавляются как стили, названные по её имени.
