    Styles de couleur

    Un style de couleur est une couleur nommée utilisée par des objets du dessin. Modifiez le style et tous les objets remplis avec lui changent aussi : les couleurs d'une création restent cohérentes et il est rapide d'essayer d'autres jeux de couleurs. Les styles sont listés dans le panneau Styles de couleur ; ouvrez-le depuis Fenêtre > Panneaux.

    Créer des styles de couleur#

    • Nouveau à partir de la sélection ajoute un style pour chaque couleur de surface des objets sélectionnés qui n'est pas encore un style.
    • Nouveau style de couleur ajoute un style à partir de la couleur actuelle du panneau Couleur.

    Utiliser et modifier les styles#

    Chaque style affiche sa couleur, son nom et trois boutons :

    • cliquez sur la couleur pour la changer : les objets remplis avec cette couleur suivent ;
    • cliquez sur le nom pour le renommer ;
    • Surface remplit la sélection avec le style, Contour colore son contour ;
    • x supprime le style (les objets gardent leur couleur).

    Harmonies#

    L'Éditeur d'harmonies crée un ensemble de styles qui vont bien ensemble, à partir d'une Couleur de base :

    1. Choisissez la Couleur de base.
    2. Cliquez sur une harmonie : Analogue, Complémentaire, Complémentaire divisée, Triadique, Tétradique ou Monochromatique.

    Les couleurs de l'harmonie sont ajoutées comme styles, nommés d'après elle.
