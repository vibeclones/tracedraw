    Ta strona nie jest jeszcze przetłumaczona i jest wyświetlana po angielsku.

    Drawing lines and curves

    A line in TraceDraw is a curve: a path made of segments that join at nodes. Segments can be straight or curved. A curve can be open, with two ends, or closed, when its end meets its start, and then it can be filled.

    The curve tools are in the Curve flyout of the toolbox. Every one of them draws a curve with the default fill and outline of new objects; change them afterwards in the Properties panel or with the color palette.

    Freehand#

    The Freehand tool (F5) draws a line where you drag, like a pencil.

    1. Choose the Freehand tool.
    2. Drag on the page. Release the button to finish.

    TraceDraw follows the pointer and smooths the line when you release it. The smoothing (0 to 100, 50 at first) on the property bar sets how much: a higher value gives fewer nodes and a softer line. When you are zoomed in, the line keeps more detail.

    To draw a straight line with this tool, click where the line starts and click again where it ends. Hold Ctrl to keep the line to steps of 15 degrees. Esc drops the first click.

    2-Point Line#

    The 2-Point Line tool draws one straight segment: press where it starts and release where it ends, or click twice. Hold Ctrl to keep it to steps of 15 degrees.

    Bezier#

    The Bezier tool draws precise curves node by node.

    1. Choose the Bezier tool.
    2. Click to place a corner node (a cusp), or drag to place a smooth node and pull out its handles, which set the direction and the bend of the curve.
    3. Go on placing nodes.
    4. Double-click or press Enter to finish. To close the curve, click its first node. Esc throws away the curve you are drawing.

    Hold Ctrl to place the next node in steps of 15 degrees from the last one, or to turn a handle in such steps. Every node snaps to what snapping is set to; see Snapping.

    Pen#

    The Pen tool places nodes the same way as the Bezier tool: click for a corner node, drag for a smooth node, double-click or Enter to finish, click the first node to close. While the button is down, the handle follows the pointer, so you see the curve take shape.

    B-Spline#

    The B-Spline tool draws smooth curves from control points, without handles.

    1. Click to place each control point. The curve follows the points, starting at the first and ending at the last, and always stays inside them. While you draw, the control points show as a dashed line.
    2. Double-click or press Enter to finish. Click the first point (once there are three) to close the curve into a smooth loop.

    The result is an ordinary curve; the control points are not kept.

    Polyline#

    The Polyline tool draws straight segments one after the other: click to add each corner, and double-click or press Enter to finish. Hold Ctrl to keep each segment to steps of 15 degrees.

    3-Point Curve#

    The 3-Point Curve tool draws an arc through three points:

    1. Drag from where the curve starts to where it ends.
    2. Move the pointer to bend the curve, and click the point it passes through.

    Continuing a curve#

    To add to an open curve, select it, then draw with the Freehand, 2-Point Line, Bezier, Pen, B-Spline or Polyline tool starting (or ending) on one of its end nodes. The new line becomes part of the curve:

    • it runs on from that end;
    • when it ends on the curve's other end, the curve closes;
    • when it ends on an end of another part of the same curve, the two parts join.

    The pointer shows a node with a line going on from it when you are over an end node, and a ring when a click would close the curve. The curve keeps its look and stays selected, and the change is one undo step. Closed curves, several selected objects and objects inside groups are never continued. The distance that counts as "on the node" is set on the Curve tools page of the tool options; see Tool options.

    The property bar#

    While a curve tool is active, the property bar shows the position, size, scale, angle and mirror buttons of the selection, its outline width, line style and start and end arrowheads, and a button that closes an open curve. The Freehand tool adds the smoothing. With nothing selected, it reminds you how to finish a curve. See Outlines for the outline settings.

    Editing curves afterwards#

    Use the Shape tool to move, add and delete nodes, change their type and bend segments; see Shaping curves with the Shape tool.
