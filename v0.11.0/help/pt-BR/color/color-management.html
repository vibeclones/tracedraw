    Gerenciamento de cores

    As telas mostram cores com luz vermelha, verde e azul; as impressoras misturam tintas ciano, magenta, amarela e preta. O gerenciamento de cores usa perfis de cor para descrever cada dispositivo, para que uma cor mantenha a aparência da tela até a página impressa. As configurações ficam em Ferramentas > Gerenciamento de cores, a caixa de diálogo Configurações de gerenciamento de cores. Nada muda até você clicar em OK.

    Os perfis do desenho#

    A guia Documento define os perfis do desenho ativo.

    • Perfis atuais mostra os perfis RGB, CMYK e de escala de cinza que o desenho usa agora.
    • Escolha como um novo perfil é aplicado:
      • Atribuir novo (preservar os valores das cores): os valores das cores ficam e a aparência muda para o novo perfil;
      • Converter (preservar a aparência das cores): as cores CMYK são convertidas para terem a mesma aparência no novo perfil.
    • Escolha os perfis Perfil RGB, Perfil CMYK e Escala de cinza. Cada lista tem os perfis padrão e depois todos os perfis encontrados no seu computador. Carregar perfis de cor acrescenta arquivos de perfil (.icc, .icm).
    • Modo de cor principal: CMYK ou RGB.
    • Intenção de renderização: como as cores que não podem ser mostradas são trazidas para dentro: Colorimétrico relativo (de início), Perceptual, Saturação ou Colorimétrico absoluto.

    O perfil CMYK acompanha o desenho, também em arquivos .cdr a partir da versão 16.

    Padrões para novos desenhos#

    A guia Padrão define o que os novos desenhos usam e como as cores são convertidas.

    • Predefinição: configurações prontas para a América do Norte, a Europa, o Japão ou trabalho para web e tela. Salvar predefinição salva suas configurações com um Nome da predefinição; Excluir predefinição remove uma.
    • Os perfis padrão Perfil RGB, Perfil CMYK e Perfil de escala de cinza, o Modo de cor principal e a Intenção de renderização.
    • Conversão de cores:
      • Mecanismo de cores: Mecanismo ICC do TraceDraw, que usa os perfis, ou Fórmulas embutidas;
      • Preservar preto puro: cores só de tinta preta continuam só de tinta preta ao serem convertidas;
      • Mapear cinza para preto CMYK (ativado de início): cinzas convertidos em CMYK usam só tinta preta;
      • Compensação de ponto preto (ativado de início): mantém separados os tons mais escuros.
    • Política de abertura: o que acontece com o perfil de um arquivo aberto, para RGB, CMYK e escala de cinza: Usar o perfil de cor incorporado, Atribuir o perfil de cor padrão ou Converter para o perfil de cor padrão. Avisar quando o perfil de cor for diferente e Avisar quando faltar o perfil de cor mostram uma mensagem na barra de status quando um arquivo tem outro perfil ou nenhum.
    • Política de importação e colagem: Converter para o perfil de cor do documento ou Atribuir o perfil de cor do documento, para o que você importa ou cola.
    • Definição das cores especiais: se as cores especiais são definidas por Valores Lab, Valores CMYK ou Valores RGB.

    Visualizar as cores de impressão#

    Exibir > Provar cores, ou o botão de prova na ponta direita da barra de status, mostra o desenho como ele seria impresso: cores que as tintas CMYK não conseguem imprimir ficam mais apagadas. O painel Cor também avisa sobre essas cores.

    Sem perfis carregados, o TraceDraw converte as cores com o próprio modelo de tintas de processo em papel revestido.
