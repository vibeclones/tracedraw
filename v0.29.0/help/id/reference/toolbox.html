    Kotak alat

    Kotak alat memuat setiap alat menggambar dan menyunting, dalam kelompok. Tombol dengan panah kecil membuka menu lipat berisi alat lain di kelompoknya. Halaman ini mencantumkan setiap alat dengan pintasannya dan halaman yang menjelaskannya. Untuk mengubah tombol alat, lihat Opsi kustomisasi.
