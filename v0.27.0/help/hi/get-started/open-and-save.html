    TraceDraw सहायता/शुरुआत करें/Opening and saving drawings

    यह पेज अभी अनुवादित नहीं है और अंग्रेज़ी में दिखाया गया है।

    Opening and saving drawings

    TraceDraw saves drawings in its own format, .tdraw, which keeps everything, and can also save .cdr files. It opens many other formats; see Supported file formats.

    Opening a drawing#

    1. Choose File > Open (Ctrl+O), or click Open on the standard toolbar.
    2. Choose the file and confirm.

    The drawing opens in a new tab. To open a drawing you used recently, use File > Open Recent, the arrow of the Open button, or the list on the Welcome Screen; Clear list empties the list. To take one drawing off the Welcome Screen list, point at it and click the x at its right, or right-click it and choose Remove from list; the file itself stays where it is. File > Import (Ctrl+I) instead adds the content of a file to the drawing that is open; see Importing files.

    Notes after opening#

    When some objects of an opened file could not be read, or the drawing uses fonts that are not installed on your computer, a message says so after the file opens:

    • For objects that could not be read, it gives their number. A Report button opens a new issue for the file on the project's issue tracker, so the problem can be fixed.
    • For missing fonts, it names them. The text shows in a similar font and keeps its font name, so it comes back as it was on a computer that has the font.

    Tick Do not show this message again to stop these messages. You can turn them on again on the Warnings page of Tools > Options > Global.

    Saving a drawing#

    Choose File > Save (Ctrl+S) to write the drawing back to its file. A new drawing, or one opened from a format TraceDraw only reads, has no file yet, so Save opens the Save Drawing dialog box.

    Save As#

    File > Save As (Ctrl+Shift+S) saves the drawing under another name, in another folder or in another format.

    To save a drawing under a new name:

    1. Choose the folder. The list on the left has shortcuts to Home, Desktop, Documents, Downloads and Pictures, and to the drives. Up one level goes to the folder above; you can also type a folder in the path bar and press Enter. New folder makes a folder and opens it. Double-click a folder of the list to open it; click a file to take its name.
    2. Type the File name. The extension of the chosen type is added.
    3. Choose Save as type: TraceDraw (*.tdraw) or CDR files (*.cdr).
    4. Choose the Version. For TraceDraw files it is the version of the format, newest first. For .cdr files it is the version of the file, from 27 down to 14; an older program can only open a version as old as itself or older. The version you choose stays with the drawing, so Save writes it again without asking.
    5. For .cdr files from version 16, Embed colour profile stores the drawing's CMYK profile in the file, and Embed fonts stores the fonts the text uses when their license allows it. Both choices are kept for the next time.
    6. Optionally fill in Title, Subject and a Rating (click the lit last star again to take it off). They are the drawing's properties, also shown in Document properties.
    7. Click Save or press Enter. If the file exists, TraceDraw asks whether to Replace it.

    The dialog box starts in the drawing's folder, else in the folder you saved to last, else in your documents folder.

    Note: In the browser version every save is a download: the dialog box keeps the name, type, version and properties, and the browser puts the file in its downloads folder.

    Other ways to save: File > Save as Template saves a template (see Templates), Export writes other formats (see Exporting), Publish to PDF writes a PDF (see Publishing to PDF), Send To saves a PDF to your desktop or documents folder or attaches it to an email, and GitHub keeps drawings in a GitHub repository (see GitHub). Revert goes back to the version last saved.

    Closing drawings#

    Choose File > Close (Ctrl+F4), click the close button on the drawing's tab, or middle-click the tab. Close All closes every drawing, and Exit (Alt+F4) closes TraceDraw.

    When a drawing has unsaved changes, TraceDraw asks whether to save them first: Yes saves (asking for a name if the drawing has no file yet), No closes without saving, and Cancel keeps the drawing open. When several drawings have changes, it asks about each one; Cancel stops.

    Auto-backup and recovery#

    On the desktop, TraceDraw keeps backups of your open drawings while auto-backup is on (the Save page of Tools > Options > TraceDraw sets how often and where; every 20 minutes at first). Closing TraceDraw normally removes them.

    If TraceDraw ended without closing, for example after a power cut, it offers the backups the next time it starts: Recover opens each one as an unsaved drawing (Save then asks where to save it), and Discard leaves the backups in their folder. Two TraceDraw windows running at once never offer each other's drawings.
