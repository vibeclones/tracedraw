    Script e automazione

    Gli script automatizzano il lavoro ripetitivo: disegnare forme a partire da dati, modificare molti oggetti in una volta o aggiungere un formato di file. Si scrivono in JavaScript nel pannello Script (Strumenti > Script > Pannello Script).

    Scrivere ed eseguire script#

    Uno script lavora con gli oggetti di TraceDraw: Application, ActiveDocument, ActivePage, ActiveLayer e le forme, i riempimenti, i contorni, i colori, le curve e gli effetti. Ad esempio:

    for (let i = 0; i < 5; i++) {
  ActiveLayer.CreateRectangle(10 + i * 25, 10, 20, 20);
}
    • Esegui esegue lo script. Le sue modifiche sono un unico passaggio di annullamento.
    • Registra registra ciò che fai come script (anche Strumenti > Script > Registra macro).
    • Carica e Salva aprono e salvano gli script; Esegui script esegue un file di script.
    • Cancella svuota l'editor; l'Output mostra ciò che lo script stampa e i suoi errori.

    Debug#

    Sul desktop, fai clic nel margine dell'editor per impostare un punto di interruzione, poi fai clic su Debug. Lo script si ferma al punto di interruzione: Continua, Passo o Interrompi, e digita un'espressione per valutarla nel punto in cui lo script è in pausa.

    Filtri script#

    Uno script che definisce TraceDrawFilter, con un nome, delle estensioni e una funzione Import o Export, aggiunge un formato di file a Importa e Esporta. Fai clic su Installa come filtro per conservarlo; Filtri script elenca i filtri installati con Modifica e Rimuovi.

    Assistenti IA (MCP)#

    TraceDraw parla il Model Context Protocol, quindi gli assistenti IA sul tuo computer possono aprire, modificare, esaminare, esportare e salvare disegni:

    • tracedraw --mcp esegue TraceDraw senza finestra per un assistente.
    • Per permettere a un assistente di modificare il disegno aperto nella tua finestra, attiva Consenti agli agenti IA su questo computer di modificare il disegno aperto (MCP) nella pagina Generale di Strumenti > Opzioni > Globali, e dai all'assistente tracedraw --mcp-window come comando. Ogni modifica è un passaggio di annullamento che puoi revocare. Possono connettersi solo i programmi del tuo computer che hanno il token segreto scritto da TraceDraw.

    Lo strumento da riga di comando#

    Ogni download include anche tracedraw-cli, che converte i disegni tra formati senza aprire il programma, per il lavoro in serie.

    Macro#

    TraceDraw esegue progetti di macro VBA scritti per programmi di disegno (versione desktop). Strumenti > Macro > Carica progetto di macro aggiunge un progetto (.gms) o file di modulo (.bas, .cls, .frm); i progetti vengono conservati e caricati all'avvio. Il pannello Gestione macro elenca le macro: fare doppio clic su una o usare Strumenti > Macro > Esegui macro (Alt+Shift+F8) per eseguirla. Moduli, finestre di messaggio e di input della macro compaiono sullo schermo, Esc o Strumenti > Macro > Arresta macro la interrompe e tutto ciò che un'esecuzione cambia è un solo passo di annullamento. Strumenti > Macro > Editor macro (Alt+F11) mostra e modifica il codice. Le macro che chiamano funzioni di Windows o il modello a oggetti dell'editor stesso non vengono eseguite.
