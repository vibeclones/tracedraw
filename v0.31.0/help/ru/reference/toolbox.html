    Набор инструментов

    Набор инструментов содержит все инструменты рисования и правки по группам. Кнопка с маленькой стрелкой открывает выпадающую группу с остальными инструментами. На этой странице перечислены все инструменты с их клавишами и страницами, которые их объясняют. Чтобы изменить клавиши инструментов, см. Параметры настройки.
