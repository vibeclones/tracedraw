    A versão para navegador

    Tradução automática: esta página pode estar atrasada em relação à versão em inglês.

    Você pode usar o TraceDraw no navegador sem instalar nada. É o mesmo programa da versão para computador, compilado para o navegador, então os menus, as ferramentas e os arquivos são os mesmos.

    A mensagem ao abrir#

    Cada vez que a página abre, uma mensagem explica que a versão para navegador é o mesmo programa da versão para computador e o que muda. OK (ou Enter) a fecha; um segundo botão abre os downloads da versão para computador.

    O que muda em relação ao computador#

    • Velocidade. Desenhos grandes, efeitos pesados, vetorização, mosaicos e exportações grandes são mais lentos e deixam a página ocupada até terminar. A versão para computador roda em velocidade total.
    • Arquivos. Abrir e importar usam o seletor de arquivos do navegador; salvar, exportar e imprimir baixam um arquivo. Os desenhos recentes não são listados, porque o navegador não consegue reabrir um arquivo enviado.
    • Fontes. A página traz as próprias fontes e busca mais na primeira vez que o texto precisa delas.
    • Configurações ficam guardadas naquele navegador, naquele computador.
    • Teclas. Enquanto o desenho tem o foco, os atalhos do programa vão para o TraceDraw e não para o navegador, exceto as teclas da área de transferência, recarregar e as ferramentas de desenvolvedor do navegador. Ctrl+N, Ctrl+T e Ctrl+W sempre ficam com o navegador, então use o menu Arquivo para criar e fechar desenhos.
    • Telas. É adequada a um navegador de computador com mouse e teclado. Em um tablet, use o espaço de trabalho Toque (veja Espaços de trabalho); a tela de um celular é pequena demais para editar.
    • Macros. Projetos de macro só carregam e rodam na versão para computador. No navegador, qualquer comando de macro mostra uma mensagem avisando, com um botão para baixar o aplicativo.
    • Atualizações. A versão para navegador é sempre a mais recente; não há nada para instalar. Instalada como app, ela mantém a versão usada por último e pega uma nova na próxima vez que abrir depois de todas as suas janelas terem sido fechadas; veja Tablets e o app para Android.
    • Desenhos não salvos. Fechar ou recarregar a aba, ou sair da página, com alterações não salvas pergunta antes, com a pergunta do próprio navegador. Os backups automáticos ficam no armazenamento do navegador para o site, e a próxima visita oferece o que uma aba fechada, recarregada ou travada deixou, como a versão para computador faz depois de uma falha (veja Backup automático e recuperação). Limpar os dados do site os remove.
    • Pressão da caneta. Uma caneta funciona como mouse, mas o navegador não repassa a pressão, então os traços têm largura uniforme.
