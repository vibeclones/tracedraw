    Tabs, columns, bullets and drop caps

    The Text menu has four dialog boxes for laying out paragraph text. Each acts on the selected paragraph text. Their settings are also in the Frame section of the Text panel.

    Tabs#

    Text > Tabs sets where the Tab character jumps to. At first there is a tab stop every 12.7 mm (half an inch).

    1. Select the paragraph text.
    2. Choose Text > Tabs.
    3. Under Tab stops, change the positions, or click Add tab to add one.
    4. Click Close.

    Columns#

    Text > Columns splits a text frame into columns; the text flows from one column into the next.

    1. Select the paragraph text.
    2. Choose Text > Columns.
    3. Set the number of Columns and the Gutter, the space between columns (5 mm at first).
    4. Click Close.

    To break to the next column at a given place, insert Column/Frame Break from Insert Formatting Code.

    Bullets#

    Text > Bullets puts a bullet before each paragraph.

    1. Select the paragraph text.
    2. Choose Text > Bullets.
    3. Tick Use bullets, and set the bullet Symbol and the Indent (5 mm at first).
    4. Click Close.

    Drop caps#

    A drop cap is a large first letter that spans several lines.

    1. Select the paragraph text.
    2. Choose Text > Drop Cap.
    3. Tick Use drop cap and set the Lines dropped (3 at first).
    4. Click Close.

    The letter is scaled so its top meets the top of the first line and it sits on the baseline of the last line it spans; the lines beside it are shortened to make room.

    Hyphenation#

    Text > Use Hyphenation lets the selected text's words break at the end of lines (while you type in a text, the paragraphs at the cursor; with no text selected, it is the setting for new text), with at least two letters before and three after the break. A comma or other punctuation next to a word does not stop it from breaking, and words with an apostrophe (such as Italian dell'anno) break too. Words with a capital letter are never broken. To decide yourself where a word may break, see Custom hyphens.
