    脚本和自动化

    脚本可以自动完成重复性工作：根据数据绘制形状、一次更改许多对象，或添加一种文件格式。脚本在 脚本 面板（工具 > 脚本 > 脚本面板）中用 JavaScript 编写。

    编写和运行脚本#

    脚本使用 TraceDraw 的对象：Application、ActiveDocument、ActivePage、ActiveLayer，以及形状、填充、轮廓、颜色、曲线和效果。例如：

    for (let i = 0; i < 5; i++) {
  ActiveLayer.CreateRectangle(10 + i * 25, 10, 20, 20);
}
    • 运行 运行脚本。其更改为一个撤消步骤。
    • 录制 将你的操作录制为脚本（也可用 工具 > 脚本 > 录制宏）。
    • 加载 和 保存 打开和保存脚本；运行脚本 运行脚本文件。
    • 清除 清空编辑器；输出 显示脚本打印的内容及其错误。

    调试#

    在桌面版中，单击编辑器的边距可设置断点，然后单击 调试。脚本在断点处停止：可以 继续、单步 或 停止 它，也可以输入表达式，在脚本暂停处对其求值。

    脚本过滤器#

    定义了 TraceDrawFilter（带有名称、扩展名以及 Import 或 Export 函数）的脚本会向 导入 和 导出 添加一种文件格式。单击 安装为过滤器 保留它；脚本过滤器 列出已安装的过滤器，并带有 编辑 和 移除。

    AI 助手（MCP）#

    TraceDraw 支持模型上下文协议（Model Context Protocol），因此你计算机上的 AI 助手可以打开、编辑、检查、导出和保存绘图：

    • tracedraw --mcp 在没有窗口的情况下为助手运行 TraceDraw。
    • 要让助手编辑你窗口中打开的绘图，请在 工具 > 选项 > 全局 的 常规 页面上打开 允许此计算机上的 AI 代理编辑打开的绘图 (MCP)，并将 tracedraw --mcp-window 作为命令提供给助手。每项更改都是一个可以撤回的撤消步骤。只有你计算机上持有 TraceDraw 所写秘密令牌的程序才能连接。

    命令行工具#

    每个下载包中还有 tracedraw-cli，它无需打开程序即可在格式之间转换绘图，适合批量处理。

    宏#

    TraceDraw 可以运行为绘图程序编写的 VBA 宏项目（桌面版）。工具 > 宏 > 加载宏项目 添加一个项目（.gms）或模块文件（.bas、.cls、.frm）；项目会被保留并在启动时加载。宏管理器 列出其中的宏：双击某个宏或使用 工具 > 宏 > 运行宏（Alt+Shift+F8）运行它。宏的窗体、消息框和输入框会显示在屏幕上，Esc 或 工具 > 宏 > 停止宏 可停止它，一次运行所做的全部更改为一个撤销步骤。工具 > 宏 > 宏编辑器（Alt+F11）显示并编辑代码。调用 Windows 函数或编辑器自身对象模型的宏无法运行。
