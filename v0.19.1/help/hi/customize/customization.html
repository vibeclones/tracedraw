    TraceDraw सहायता/अनुकूलन और स्वचालन/Customization options

    यह पेज अभी अनुवादित नहीं है और अंग्रेज़ी में दिखाया गया है।

    Customization options

    Tools > Options > Customization sets the look of the interface, your own keyboard shortcuts, which bars show and how the color palette behaves.

    Appearance#

    • Center dialog boxes: dialog boxes open in the middle of the window; off, they open where you left them.
    • Shadows under menus and dialogs (fewer shadows help slower graphics).
    • Coloured tool icons: each group of tools gets a color of its own.
    • Size: how large menus, bars, icons and panels are, relative to the scaling your system gives the monitor (100% at first). Reset to default goes back to 100%. The interface size never changes the size of your drawing. Grow with the desktop text size (now {n} %) makes it grow with the desktop text size.
    • Color: the Theme (Light, Medium Light, Medium Dark, Dark or High Contrast), Use high contrast while the desktop has a high contrast theme on, and the Desktop color around the page. The button at the right end of the status bar switches between light and dark.

    Commands#

    The page lists every command of the menus, with its shortcut, and the tool keys. Type in Find to filter the list.

    To give a command your own shortcut:

    1. Click the command's shortcut button.
    2. Press the keys, such as Ctrl+Alt+K. Esc stops waiting.

    Your shortcuts come before the built-in ones: when you take a key another command uses, the page says which command lost it. The menus show your shortcut. The x beside a shortcut removes it, and resetting to the defaults removes them all. Tool keys are a letter or Shift and a letter. See Keyboard shortcuts.

    Command Bars#

    Show these bars Menu Bar, Standard, Property Bar, Toolbox, Status Bar, Color Palette, and the Text, Zoom and Transform toolbars. Reset puts the bars back. Under Other: Lock Toolbars and Show the Outline flyout in the toolbox.

    While these pages are open (or with Alt held), drag a button of the Standard or Zoom toolbar to move it, or off the bar to remove it. Drag a command from the Commands page onto one of these bars to add it. Reset on the Command Bars page brings the first buttons back.

    Color Palette#

    • Automatically update the document palette and Show the document palette (both on).
    • Color swatches: Show "No Color" well (on), and what the Right mouse button does: Set outline color (at first) or open the Context menu.

    See Color palettes.
