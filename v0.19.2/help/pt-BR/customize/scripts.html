    Scripts e automação

    Os scripts automatizam trabalho repetitivo: desenhar formas a partir de dados, mudar muitos objetos de uma vez ou acrescentar um formato de arquivo. Eles são escritos em JavaScript no painel Scripts (Ferramentas > Scripts > Painel de scripts).

    Escrever e executar scripts#

    Um script trabalha com os objetos do TraceDraw: Application, ActiveDocument, ActivePage, ActiveLayer e as formas, preenchimentos, contornos, cores, curvas e efeitos. Por exemplo:

    for (let i = 0; i < 5; i++) {
  ActiveLayer.CreateRectangle(10 + i * 25, 10, 20, 20);
}
    • Executar executa o script. As alterações dele são um passo de desfazer.
    • Gravar grava o que você faz como script (também Ferramentas > Scripts > Gravar macro).
    • Carregar e Salvar abrem e salvam scripts; Executar script executa um arquivo de script.
    • Limpar esvazia o editor; a Saída mostra o que o script imprime e os erros.

    Depuração#

    No desktop, clique na margem do editor para definir um ponto de parada, depois clique em Depurar. O script para no ponto de parada: Continuar, Passo ou Parar, e digite uma expressão para avaliá-la onde o script está pausado.

    Filtros de script#

    Um script que define TraceDrawFilter, com um nome, extensões e uma função Import ou Export, acrescenta um formato de arquivo a Importar e Exportar. Clique em Instalar como filtro para guardá-lo; Filtros de script lista os filtros instalados com Editar e Remover.

    Assistentes de IA (MCP)#

    O TraceDraw fala o Model Context Protocol, então assistentes de IA no seu computador podem abrir, editar, inspecionar, exportar e salvar desenhos:

    • tracedraw --mcp executa o TraceDraw sem janela para um assistente.
    • Para deixar um assistente editar o desenho aberto na sua janela, ligue Deixar agentes de IA deste computador editarem o desenho aberto (MCP) na página Geral de Ferramentas > Opções > Global, e dê ao assistente tracedraw --mcp-window como comando. Cada alteração é um passo de desfazer que você pode voltar. Só programas no seu computador com o token secreto que o TraceDraw grava podem se conectar.

    A ferramenta de linha de comando#

    Todo download também traz tracedraw-cli, que converte desenhos entre formatos sem abrir o programa, para trabalho em lote.

    Macros#

    O TraceDraw executa projetos de macros VBA escritos para programas de desenho (versão para desktop). Ferramentas > Macros > Carregar projeto de macros adiciona um projeto (.gms) ou arquivos de módulo (.bas, .cls, .frm); os projetos ficam guardados e carregam ao iniciar. O Gerenciador de macros lista as macros: clique duas vezes numa delas ou use Ferramentas > Macros > Executar macro (Alt+Shift+F8) para executá-la. Formulários, caixas de mensagem e de entrada da macro aparecem na tela, Esc ou Ferramentas > Macros > Parar macro interrompe, e tudo o que uma execução muda é um único passo de desfazer. Ferramentas > Macros > Editor de macros (Alt+F11) mostra e edita o código. Macros que chamam funções do Windows ou o modelo de objetos do próprio editor não funcionam.
