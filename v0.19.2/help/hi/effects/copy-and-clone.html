    TraceDraw सहायता/विशेष प्रभाव/Copying and cloning effects

    यह पेज अभी अनुवादित नहीं है और अंग्रेज़ी में दिखाया गया है।

    Copying and cloning effects

    Instead of setting up an effect again, you can copy it from an object that already has it.

    Copying an effect#

    1. Select the objects that should get the effect.
    2. Choose Object > Copy Effect and the kind of effect: Drop Shadow From, Transparency From, Envelope From, Perspective From, Distortion From, Extrude From, Contour From, Blend From, Lens From, Bevel From or Block Shadow From.
    3. Click the object to copy from. A right-click cancels.

    The effect is fitted to each object: an envelope or perspective is stretched to its size, a distortion keeps its center at the same place within it. When the object you click has no such effect, nothing changes and the status bar says so. The copy is one undo step.

    Cloning an effect#

    Object > Clone Effect copies the shadow (Shadow From) or the transparency (Transparency From) of another object, and keeps following it: change the source and the clones change too, until you edit a clone's own effect.

    Edit > Clone makes a clone of a whole object, and Copy Properties From copies the fill, outline or text properties of another object.
