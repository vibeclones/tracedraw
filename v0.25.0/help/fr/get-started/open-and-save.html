    Ouvrir et enregistrer des dessins

    TraceDraw enregistre les dessins dans son propre format, .tdraw, qui conserve tout, et peut aussi enregistrer des fichiers .cdr. Il ouvre de nombreux autres formats ; voir Formats de fichier pris en charge.

    Ouvrir un dessin#

    1. Choisissez Fichier > Ouvrir (Ctrl+O), ou cliquez sur Ouvrir dans la barre d'outils standard.
    2. Choisissez le fichier et confirmez.

    Le dessin s'ouvre dans un nouvel onglet. Pour ouvrir un dessin utilisé récemment, utilisez Fichier > Ouvrir un fichier récent, la flèche du bouton Ouvrir ou la liste de l'écran d'accueil ; Effacer la liste vide la liste. Pour retirer un seul dessin de la liste de l'écran d'accueil, pointez-le et cliquez sur le x à sa droite, ou cliquez dessus avec le bouton droit et choisissez Remove from list ; le fichier lui-même reste à sa place. Fichier > Importer (Ctrl+I) ajoute plutôt le contenu d'un fichier au dessin ouvert ; voir Importer des fichiers.

    Messages après l'ouverture#

    Quand certains objets d'un fichier ouvert n'ont pas pu être lus, ou que le dessin utilise des polices qui ne sont pas installées sur votre ordinateur, un message l'indique après l'ouverture du fichier :

    • Pour les objets qui n'ont pas pu être lus, il en donne le nombre. Un bouton Signaler ouvre un nouveau ticket pour le fichier dans le suivi des problèmes du projet, afin que le problème puisse être corrigé.
    • Pour les polices manquantes, il les nomme. Le texte s'affiche dans une police semblable et garde son nom de police : il revient donc tel qu'il était sur un ordinateur qui possède la police.

    Cochez Ne plus afficher ce message pour ne plus voir ces messages. Vous pouvez les réactiver dans la page Avertissements de Outils > Options > Global.

    Enregistrer un dessin#

    Choisissez Fichier > Enregistrer (Ctrl+S) pour écrire le dessin dans son fichier. Un nouveau dessin, ou un dessin ouvert depuis un format que TraceDraw sait seulement lire, n'a pas encore de fichier : Enregistrer ouvre alors la boîte de dialogue Enregistrer le dessin.

    Enregistrer sous#

    Fichier > Enregistrer sous (Ctrl+Shift+S) enregistre le dessin sous un autre nom, dans un autre dossier ou dans un autre format.

    Pour enregistrer un dessin sous un nouveau nom :

    1. Choisissez le dossier. La liste de gauche contient des raccourcis vers Dossier personnel, Bureau, Documents, Téléchargements et Images, ainsi que vers les lecteurs. Dossier parent remonte au dossier parent ; vous pouvez aussi taper un dossier dans la barre de chemin et appuyer sur Entrée. Nouveau dossier crée un dossier et l'ouvre. Double-cliquez sur un dossier de la liste pour l'ouvrir ; cliquez sur un fichier pour reprendre son nom.
    2. Tapez le Nom du fichier. L'extension du type choisi est ajoutée.
    3. Choisissez Type : TraceDraw (*.tdraw) ou Fichiers CDR (*.cdr).
    4. Choisissez la Version. Pour les fichiers TraceDraw, c'est la version du format, la plus récente en premier. Pour les fichiers .cdr, c'est la version du fichier, de 27 à 14 ; un programme plus ancien ne peut ouvrir qu'une version aussi ancienne que lui ou plus ancienne. La version choisie reste attachée au dessin : Enregistrer l'écrit donc de nouveau sans rien demander.
    5. Pour les fichiers .cdr à partir de la version 16, Incorporer le profil de couleur stocke le profil CMJN du dessin dans le fichier, et Incorporer les polices stocke les polices utilisées par le texte quand leur licence le permet. Les deux choix sont conservés pour la fois suivante.
    6. Si vous le souhaitez, remplissez Titre, Sujet et une Évaluation (cliquez de nouveau sur la dernière étoile allumée pour l'enlever). Ce sont les propriétés du dessin, affichées aussi dans Propriétés du document.
    7. Cliquez sur Enregistrer ou appuyez sur Entrée. Si le fichier existe, TraceDraw demande s'il faut le Remplacer.

    La boîte de dialogue s'ouvre dans le dossier du dessin, sinon dans le dernier dossier où vous avez enregistré, sinon dans votre dossier de documents.

    Remarque : Dans la version pour navigateur, chaque enregistrement est un téléchargement : la boîte de dialogue conserve le nom, le type, la version et les propriétés, et le navigateur place le fichier dans son dossier de téléchargements.

    Autres façons d'enregistrer : Fichier > Enregistrer comme modèle enregistre un modèle (voir Modèles), Exporter écrit d'autres formats (voir Exporter), Publier au format PDF écrit un PDF (voir Publier au format PDF), Envoyer vers enregistre un PDF sur votre bureau ou dans votre dossier de documents, ou le joint à un e-mail, et GitHub conserve les dessins dans un dépôt GitHub (voir GitHub). Rétablir revient à la dernière version enregistrée.

    Fermer des dessins#

    Choisissez Fichier > Fermer (Ctrl+F4), cliquez sur le bouton de fermeture de l'onglet du dessin, ou cliquez sur l'onglet avec le bouton du milieu. Tout fermer ferme tous les dessins, et Quitter (Alt+F4) ferme TraceDraw.

    Quand un dessin a des modifications non enregistrées, TraceDraw demande d'abord s'il faut les enregistrer : Oui enregistre (en demandant un nom si le dessin n'a pas encore de fichier), Non ferme sans enregistrer et Annuler laisse le dessin ouvert. Quand plusieurs dessins ont des modifications, il pose la question pour chacun ; Annuler arrête.

    Sauvegarde automatique et récupération#

    Sur le bureau, TraceDraw conserve des sauvegardes de vos dessins ouverts tant que la sauvegarde automatique est active (la page Enregistrer de Outils > Options > TraceDraw règle la fréquence et l'emplacement ; toutes les 20 minutes au départ). Fermer TraceDraw normalement les supprime.

    Si TraceDraw s'est arrêté sans se fermer, par exemple après une coupure de courant, il propose les sauvegardes au démarrage suivant : Récupérer ouvre chacune comme un dessin non enregistré (Enregistrer demande alors où l'enregistrer), et Ignorer laisse les sauvegardes dans leur dossier. Deux fenêtres TraceDraw ouvertes en même temps ne se proposent jamais les dessins l'une de l'autre.
