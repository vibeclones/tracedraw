    Gestion des couleurs

    Les écrans affichent les couleurs avec de la lumière rouge, verte et bleue ; les imprimantes mélangent des encres cyan, magenta, jaune et noire. La gestion des couleurs utilise des profils de couleur pour décrire chaque appareil, afin qu'une couleur garde son aspect de l'écran à la page imprimée. Les réglages se trouvent dans Outils > Gestion des couleurs, la boîte de dialogue Paramètres de gestion des couleurs. Rien ne change avant que vous cliquiez sur OK.

    Les profils du dessin#

    L'onglet Document règle les profils du dessin actif.

    • Profils actuels affiche les profils RVB, CMJN et niveaux de gris que le dessin utilise actuellement.
    • Choisissez comment un nouveau profil est appliqué :
      • Attribuer (conserver les valeurs des couleurs) : les valeurs de couleur restent et leur aspect change selon le nouveau profil ;
      • Convertir (conserver l’aspect des couleurs) : les couleurs CMJN sont converties pour garder le même aspect dans le nouveau profil.
    • Choisissez les profils Profil RVB, Profil CMJN et Niveaux de gris. Chaque liste contient les profils par défaut, puis tous les profils trouvés sur votre ordinateur. Charger des profils de couleur ajoute des fichiers de profil (.icc, .icm).
    • Mode de couleur principal : CMJN ou RVB.
    • Mode de rendu : comment les couleurs impossibles à reproduire sont ramenées : Colorimétrie relative (au départ), Perception, Saturation ou Colorimétrie absolue.

    Le profil CMJN accompagne le dessin, y compris dans les fichiers .cdr à partir de la version 16.

    Valeurs par défaut des nouveaux dessins#

    L'onglet Par défaut règle ce qu'utilisent les nouveaux dessins et la façon dont les couleurs sont converties.

    • Préréglage : des réglages prêts à l'emploi pour l'Amérique du Nord, l'Europe, le Japon, ou le travail pour le web et l'écran. Enregistrer le préréglage enregistre vos propres réglages sous un Nom du préréglage ; Supprimer le préréglage en supprime un.
    • Les profils Profil RVB, Profil CMJN et Profil niveaux de gris par défaut, Mode de couleur principal et Mode de rendu.
    • Conversion des couleurs :
      • Moteur de couleur : Moteur ICC de TraceDraw, qui utilise les profils, ou Formules intégrées ;
      • Conserver le noir pur : les couleurs faites uniquement d'encre noire restent uniquement en encre noire après conversion ;
      • Convertir le gris en noir CMJN (actif au départ) : les gris convertis en CMJN n'utilisent que l'encre noire ;
      • Compensation du point noir (actif au départ) : garde les nuances les plus sombres distinctes.
    • Règle d’ouverture : ce qui arrive au profil d'un fichier que vous ouvrez, pour le RVB, le CMJN et les niveaux de gris : Utiliser le profil de couleur incorporé, Attribuer le profil de couleur par défaut ou Convertir vers le profil de couleur par défaut. Avertir si le profil de couleur diffère et Avertir si le profil de couleur manque affichent un message dans la barre d'état quand un fichier a un autre profil ou n'en a aucun.
    • Règle d’importation et de collage : Convertir vers le profil de couleur du document ou Attribuer le profil de couleur du document, pour ce que vous importez ou collez.
    • Définition des tons directs : si les couleurs d'accompagnement sont définies par Valeurs Lab, Valeurs CMJN ou Valeurs RVB.

    Prévisualiser les couleurs d'impression#

    Affichage > Épreuve des couleurs, ou le bouton d'épreuve à l'extrémité droite de la barre d'état, montre le dessin tel qu'il serait imprimé : les couleurs que les encres CMJN ne peuvent pas imprimer paraissent plus ternes. Le panneau Couleur signale aussi ces couleurs.

    Sans profils chargés, TraceDraw convertit les couleurs avec son propre modèle d'encres quadrichromiques sur papier couché.
