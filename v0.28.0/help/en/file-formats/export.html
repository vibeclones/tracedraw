    TraceDraw Help/File formats/Exporting

    Exporting

    File > Export (Ctrl+E) writes the drawing, a page or the selection in another format. The Export dialog box shows a preview on the left and the settings on the right.

    To export#

    1. Choose File > Export.
    2. Choose a Preset to start from saved choices, or choose the format. The common formats (JPG, PDF, AI, PNG) are first. Choosing a format brings back the settings you used for it last.
    3. Set the format's options (below).
    4. Tick Selected only to export only the selection, or All pages to export every page.
    5. Click OK and choose where to save. In the browser, the file is downloaded.

    The dialog box estimates the size of the file and, for bitmap formats, says what comes out, such as "1240 x 1754 pixels, 150 dpi, sRGB". With Do not show filter dialog ticked, the next export goes straight to the file with the same choices.

    Format options#

    FormatOptions
    PNG, WebP, GIFresolution (or the size in pixels), transparent background; WebP also quality
    JPEGresolution, quality (1 to 100)
    BMP, TIFF, PSDresolution
    PDFstandard (PDF 1.4, PDF/X-1a, PDF/X-3 or PDF/X-4), bleed, output condition for PDF/X
    PDF, AItitle and tags
    SVG, EPS, AI, DXF, HTML, EMF, WMF, PLT, PS, PRNnone

    Size of bitmaps#

    For bitmap formats, Size has a width, a height and their unit (px, mm, cm or in); the other side follows the page's proportions.

    • In pixels, typing a width or height sets the resolution that gives it, so you can type the size of an icon (32 x 32 pixels) directly.
    • In a length, the size is the printed size: typing a width or height scales the artwork at the resolution you set, from 1 % to 10000 %. A button with the scale (such as "200 %") shows when it is not 100 % and puts it back.

    PNG, JPEG and BMP files record their resolution, so they open at the size you chose. PostScript and PRN files hold every exported page.

    Presets#

    The Preset list holds every preset you saved, each with its format in brackets, such as "Web PNG (PNG)". Choosing a preset of another format switches the dialog to that format; changing the format leaves no preset chosen. + saves the current choices under a name (the same name replaces that preset), the pencil renames the chosen preset and - deletes it.

    Starting choices#

    The starting choices are set on the File Formats page of the global options, where Remember the settings of the last export (on at first) makes the dialog start with the format, resolution and quality of the last export, in the next session too. Export For has presets for the web and for office documents; see Exporting for the web. For PDF files with bookmarks and security, use Publishing to PDF.
