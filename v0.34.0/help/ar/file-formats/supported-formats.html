    تعليمات TraceDraw/تنسيقات الملفات/Supported file formats

    لم تُترجم هذه الصفحة بعد وتُعرض بالإنجليزية.

    Supported file formats

    Saving#

    FormatNotes
    TraceDraw (.tdraw)the native format; keeps everything, including effects, styles, comments and fonts
    CDR (.cdr)versions 7 to 27 from Save As; keeps pages and their sizes, layers, shapes, curves, groups and their names, text, bitmaps, fills, outlines and transparency, and the fonts with Embed fonts. From version 14, blends, contours, distortions, envelopes, perspectives, extrusions, bevels, block shadows and symmetries open again in TraceDraw as live effects; other programs see the objects the effects drew. Drop shadows are written as a picture of the shadow under the object
    TraceDraw template (.tdt)from Save as Template
    A package (a folder)from Package: the drawing, its linked pictures, its fonts and a report; see Packaging a drawing

    Opening and importing#

    FormatWhat comes in
    TraceDraw (.tdraw, .tdt)everything
    CDR (.cdr), from the oldest versions to the newestpages, layers, shapes, curves, groups, text, bitmaps (CMYK pictures in the CMYK mode), fills including mesh fills, outlines, transparency, blends, embedded objects drawn as pictures (such as barcodes), embedded fonts, the color profile
    CMXpages, layers, shapes, fills, outlines, images, clips, text
    SVG, SVGZshapes, groups, clips, gradients, images, text
    PDF, AIpaths, images, text, clips, shadings, patterns; password-protected files ask for the password
    EPS, PS, PRN, older AI filespaths, images, text, clips, shadings; one page per printed page
    DXFlines, polylines, arcs, ellipses, splines, hatches, text, blocks
    EMF, WMFpaths, pens, brushes, text, bitmaps, clips
    PLT (HPGL)plotter pen strokes
    PSD, PSBthe layers as bitmaps, with opacity, visibility and masks
    PNG, JPEG, BMP, GIF, WebP, TIFFbitmaps
    TXT, RTF, DOCXparagraph text with its formatting

    Exporting#

    FormatKind
    SVG, HTMLvector, for the web
    PDF, AIvector, for print and sharing; PDF/X-1a, X-3 and X-4
    EPS, PostScript (.ps), PRNvector, for print
    DXF, PLTvector, for CAD, plotters and cutters
    EMF, WMFvector, for office programs
    PNG, JPEG, WebP, GIF, BMP, TIFFbitmap
    PSDbitmap, one layer per layer of the drawing

    Scripts can add more formats to importing and exporting; see Scripts.
