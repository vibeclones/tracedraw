    Finding and replacing by properties

    The Properties mode of the Find and Replace panel finds objects by how they look and what they are: every object filled with one red, every outline 0.2 mm wide, every text in a font you no longer want, every bitmap. It then selects them, or changes their fill, outline or font all at once.

    Finding objects#

    1. Choose Edit > Find and Replace (Ctrl+F) and click Properties.
    2. In Look in, choose This page (the default) or Whole drawing (every page, then the master layers).
    3. Under Find objects with, tick what to look for. An object is found when it has everything ticked:
      • Type (off; Rectangle at first): only objects of one kind: Rectangle, Ellipse, Polygon or star, Curve, Artistic text, Paragraph text, Group, Bitmap, Clip frame, Table or Symbol.
      • Fill (on; black at first): objects filled with this color, as a uniform fill or in a gradient or mesh fill, or None for objects without a fill.
      • Outline (off): objects whose outline has this color, or None for objects without an outline.
      • Outline width (off; 0.2 mm at first, in the outline unit): objects whose outline has this width.
      • Font (off): text that uses this font family, in any mix of capitals and small letters.
    4. To look for what an object has, select it and click From Selection: its fill color (or none), outline color (or none), outline width and font fill the fields, ticked where it makes sense (the width and the type stay unticked). Reset clears everything back to the defaults.
    5. Click a button:
      • Previous or Find Next selects the objects found one at a time, going round at the end. With Whole drawing, the page of each object comes into view.
      • Find All selects every object found on the current page. The status bar says how many were found in all and how many on this page.

    The panel shows the number of objects found.

    Replacing properties#

    1. Find the objects as above.
    2. Under Replace with, tick what to change and set the new value:
      • Fill: when a fill color is looked for, that color is replaced by the new one wherever it is used, in gradients and mesh fills too; otherwise the objects get a uniform fill of the new color.
      • Outline: when an outline color is looked for, outlines of that color take the new one; otherwise every outline does. Objects without an outline stay without one.
      • Outline width: every outline of the objects found takes the new width.
      • Font: when a font is looked for, text in that font takes the new one; otherwise all the text of the objects found does.
    3. Click Replace All.

    All the changes undo in one step. The status bar says in how many objects something changed. Locked objects, and objects on locked layers, are found but left as they are.

    How objects are compared#

    • Colors count as the same when they are in the same model with every value within half a percent, or, in different models, when they show as the same color on screen. A spot color matches the same ink at the same tint, and the registration color matches only itself.
    • Widths count as the same within half a thousandth of a millimetre.
    • In groups and clip frames, the objects inside are checked at any depth, and the group is found when one of them matches. With only Type ticked, the group's own type counts. Only objects at the top level are selected, since those are what you can select.

    To find text or names instead, see Finding and replacing.
