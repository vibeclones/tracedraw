    歡迎使用 TraceDraw 說明

    TraceDraw 是一款免費的開放原始碼向量繪圖程式。你可以用它繪製插畫、標誌、圖表、版面和印刷品，它們由在任何尺寸下都保持清晰的形狀、線條和文字組成，還能與點陣圖結合。同一個程式可在 Windows、macOS 和 Linux 以及網頁瀏覽器中執行。

    本說明一步步解釋如何在 TraceDraw 中完成工作，以及每個對話方塊、面板和工具的用途。

    本說明的編排方式#

    左側的目錄依照工作的順序排列：

    • 入門 介紹工作區、新繪圖、開啟和儲存。
    • 線條、形狀和外框、物件、符號和圖層 以及 色彩、填色和透明度 介紹繪製和排列物件。
    • 特殊效果、文字、範本和樣式、頁面和版面 以及 點陣圖 涵蓋其餘的繪圖工作。
    • 列印、網頁圖形 和 檔案格式 介紹如何把作品從 TraceDraw 輸出。
    • 自訂和自動化 介紹選項、工作區、指令碼和 AI 功能，參考 列出每個功能表命令、工具、面板和鍵盤快速鍵。

    使用 搜尋 索引標籤可依頁面中的任何字詞找到頁面，使用上方的語言清單可用另一種語言閱讀同一頁面。

    在 TraceDraw 中取得說明#

    • 按 F1 開啟眼前內容的頁面：開啟的對話方塊，否則是顯示的面板，再否則是目前的工具。
    • 按一下對話方塊或選項頁面底部的 ? 按鈕，開啟它的頁面。
    • 選擇 說明 > 說明主題 開啟本頁。
    • 提示 面板會在你工作時說明目前的工具；其中的 深入了解 連結會開啟該工具在這裡的頁面。請參閱 提示。

    頁面會在網頁瀏覽器中以 TraceDraw 設定的語言開啟。

    從哪裡開始#

    如果你剛開始使用 TraceDraw，請先閱讀 工作區，接著閱讀 建立繪圖 和 繪製線條和曲線。
