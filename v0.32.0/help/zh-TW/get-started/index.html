    TraceDraw 說明/入門

    入門

    這些頁面介紹 TraceDraw：視窗的各個部分，如何建立、開啟和儲存繪圖，如何在繪圖中移動和復原操作，以及繪圖時在哪裡取得說明。

    TraceDraw 可在 Windows、macOS 和 Linux 上執行，也可以不安裝任何東西就在網頁瀏覽器中執行。兩者是同一個程式；瀏覽器版本的少數差異在 瀏覽器版本 中說明。
