    यह पेज अभी अनुवादित नहीं है और अंग्रेज़ी में दिखाया गया है।

    Fitting objects to a path

    The Fit Objects to Path panel places objects along a line, a curve or the outline of a shape: beads on a string, letters or stars round a seal, a row of fence posts along a road, dashes of your own along a border. It can make copies to fill the path, space them evenly or at a set distance, stand them on the path or turn them with it.

    Placing objects on a path#

    1. Select the objects to place, then the path last (Shift+click). The panel shows how many objects are selected and what kind of object the path is.
    2. Choose Object > Fit Objects to Path to open the panel.
    3. Change the values you need (see below). Once a value changes, dashed outlines on the canvas show where every object and copy will go.
    4. Click Apply.

    Fitting undoes in one step. Copies go into the layer of the object they copy, with its fill, outline and effects. After an Apply that made copies, the objects placed and the copies are selected (not the path).

    The panel starts from the default values, with no outlines, each time you select other objects or work in another drawing; the values you enter stay while the same objects are selected.

    The settings#

    The panel's groups, from top to bottom:

    Objects and path#

    • Keep originals (off): the selected objects stay where they are and copies of them are placed.
    • Group all objects (off): what was placed goes into one group, which is selected.
    • Treat subpaths as contiguous (on): a path made of several pieces is walked piece after piece, as one path. Off, only the first piece is used.

    Spacing#

    • Spacing: Evenly along the path (the default) spreads the objects over the whole path; Fixed distance puts them the Distance apart (10 mm at first).
    • Measure between: between the Centers of neighbouring objects (the default) or between their Edges, so objects of different sizes get the same gap.
    • Start offset (0): moves the first object along the path from its start. A negative value is allowed.
    • End offset (0, open paths only): keeps the objects away from the end of the path.
    • Place the row at (fixed distance only): puts the row at the Start (the default), in the Middle or at the End of the path.

    Copies#

    • Each object once (the default): each selected object is placed once.
    • Number of objects (1 to 1000, 10 at first): that many objects in all: the selected ones, then copies of them in the same order.
    • Fill the path (fixed distance only): as many as fit on the path.

    There are never more than 1000 objects in all.

    Placement#

    • Placement: On the path (the default), Above the path or Below the path, with a Distance from the path (0 at first) between the objects and the path. "Above" is on the left of the path's direction.
    • Reference: the point of each object that goes on the path: its Center of rotation (the default; the centre, or where you moved it with the Pick tool), or a point of its Bounding box or Bounding box with outline.
    • Origin (box references only): one of nine points of the box, picked in the grid (the centre at first). The bottom middle point makes the objects stand on the path.

    Rotation#

    • Rotation: Rotate objects to follow the path turns each object with the direction of the path; Fixed angle (the default) turns them all alike. The Angle (0, in degrees counterclockwise) is added in either case.
    • Ignore initial rotation (off): straightens objects that were turned before they are placed.
    • Under Modify rotation, the Style adds a turn to every object:
      • None (the default): no extra turn.
      • Uniform: every object turns by the Start angle.
      • Progressive: each object turns a little more than the one before, the Spin angle (360 at first) times the Revolutions (1) over the whole row.
      • Jitter: each object turns by a different amount, up to the Range (±) (15 degrees) either way. The same object turns the same way every time, in the preview and after Apply.
      • Progressive jitter: both.

    Tick Clockwise to turn the other way. Only the fields the style uses can be changed.

    Order#

    • Order: which object goes first: As selected (the default), Reversed, Left to right, Right to left, Largest first, Smallest first, Large and small in turn, Top to bottom, Bottom to top, Tall to short, Short to tall, Wide to narrow, Narrow to wide or Random (shuffled the same way each time for the same objects).
    • Reverse direction (off): starts from the other end of the path.

    Tips and limits#

    • On a closed shape the objects go all the way round, the closing side included, without the first and last meeting.
    • On an open path, an object that would land past an end stays at that end.
    • With more than 200 objects each one previews as its box; with more than 200 selected there is no preview, but Apply works.
    • To place text along a path instead, see Adding and editing text. To spread objects in a straight row, see Aligning and distributing.
