    自定义选项

    机器翻译：本页可能落后于英文版。

    工具 > 选项 > 自定义 设置界面外观、你自己的键盘快捷键、显示哪些栏以及调色板的行为。

    外观#

    • 对话框居中：对话框在窗口中央打开；关闭时，它们在你上次放置的位置打开。
    • Shadows under menus and dialogs（阴影越少，对较慢的显卡越有利）。
    • Coloured tool icons：每组工具都有自己的颜色。
    • 大小：菜单、栏、图标和面板的大小，相对于系统为显示器设置的缩放比例（起初为 100%）。重置为默认值 恢复为 100%。界面大小从不改变绘图的大小。Grow with the desktop text size (now {n} %) 使其随桌面文本大小变大。
    • 颜色：主题（浅色、中浅色、中深色、深色或高对比度）、Use high contrast while the desktop has a high contrast theme on，以及页面周围的 桌面颜色。状态栏右端的按钮在浅色和深色之间切换。

    命令#

    该页面列出菜单中的每个命令及其快捷键，以及工具按键。在 查找 中输入可筛选列表。

    为命令设置你自己的快捷键：

    1. 单击该命令的快捷键按钮。
    2. 按下按键，例如 Ctrl+Alt+K。Esc 停止等待。

    你的快捷键优先于内置快捷键：当你占用另一个命令使用的按键时，页面会说明哪个命令失去了它。菜单显示你的快捷键。快捷键旁的 x 删除它，重置为默认值会将它们全部删除。工具按键为一个字母，或 Shift 加一个字母。请参阅 键盘快捷键。

    一个命令可以有多个快捷键：新按键会加入已有的按键（内置按键仍可同时使用），每个按键都有自己的删除按钮。运行菜单命令的工具栏按钮（新建、打开、保存、撤销、放大等）也可以设置快捷键，与其菜单命令相同；菜单只在某些时候显示的行也是如此。“工具栏按钮”列表包含标准工具栏和缩放工具栏的所有按钮：可从这里把移除的按钮拖回工具栏。

    命令栏#

    显示以下栏 菜单栏、标准、属性栏、工具箱、状态栏、调色板，以及 文本、缩放 和 变换 工具栏。重置 恢复各栏。在 其他 下：锁定工具栏 和 在工具箱中显示轮廓展开工具栏。

    While these pages are open (or with Alt held), drag a button of the Standard or Zoom toolbar to move it, or off the bar to remove it. Drag a command from the Commands page onto one of these bars to add it. Reset on the Command Bars page brings the first buttons back.

    调色板#

    • 自动更新文档调色板 和 显示文档调色板（均打开）。
    • 色样：显示“无颜色”色井（打开），以及 鼠标右键 的作用：设置轮廓颜色（起初选用）或打开 上下文菜单。

    请参阅 调色板。
