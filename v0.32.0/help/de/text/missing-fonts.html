    Missing fonts

    A drawing made on another computer can use fonts that are not installed on yours. TraceDraw always shows such text in an installed font that looks close, and keeps the text's own font name. When the drawing opens, the Missing Fonts dialog box lets you choose which installed font draws each missing one, for now or for good.

    Choosing the fonts that stand in#

    When you open a drawing with missing fonts, the Missing Fonts dialog box lists them:

    1. Each row shows the Missing font and the font it is Drawn with now. The first choice in the list is the font TraceDraw picked by itself, marked "(automatic)": a font drawn to the same widths when there is one, else one of the same style.
    2. To use another font, open the list of the row and click an installed family. Type part of a name in Find a font to narrow the lists.
    3. Choose how long the choice holds:
      • For this session only (the drawing keeps its fonts) (the default): the font you chose draws the text until TraceDraw closes, bold and italic text included. The drawing keeps its own font names, so it is saved with them and shows in its own fonts on a computer that has them.
      • Replace in the drawing (saved with it): every text in the missing family, also in groups, clip frames, tables and symbols, takes the font you chose. This changes the drawing and undoes in one step.
    4. Click OK.

    Cancel, Esc or the close button change nothing: the automatic fonts stay. Either way, the status bar then names the fonts still missing and the fonts that draw them, or says they were replaced. When some objects of the file could not be read, their note follows the dialog box.

    Turning the dialog box off and on#

    Tick Do not show this message again in the dialog box to stop it. The drawing then opens straight away and the status bar names the missing fonts. Click that note on the status bar to open the Warnings page of Tools > Options > Global, where Ask which installed font draws each missing one (the Missing Fonts dialog) turns the dialog box on again (it is on at first).

    When an opened drawing uses fonts that are not installed, on the same page, is a separate, plain message that only names the missing fonts after the drawing opens.

    Opening drawings from scripts, the command line or the AI connection never stops at this dialog box.

    Other ways to deal with missing fonts#

    • Install the fonts, or add their folder in the Font Manager (see Fonts and glyphs); the text then shows in them.
    • In the Fonts panel, families the drawing uses that are not installed are marked missing.
    • Drawings saved as .tdraw and .cdr files with Embed fonts carry their fonts along, and a package holds the font files in its Fonts folder.
    • The preflight lists text in fonts that are not installed before you print or publish.
