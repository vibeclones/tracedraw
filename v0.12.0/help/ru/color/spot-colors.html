    Плашечные цвета

    Плашечный цвет это именованная краска, которая печатается со своей отдельной формы, например металлик или фирменный цвет, вместо того чтобы смешиваться из голубой, пурпурной, жёлтой и чёрной. Каждый рисунок хранит список своих плашечных красок. У каждой краски есть замена из триадных цветов, которая показывает её на экране и используется везде, где краску применить нельзя.

    Добавление плашечной краски#

    1. Откройте панель Цвет и смешайте цвет, на который должна быть похожа краска.
    2. В разделе Плашечные краски введите Имя краски.
    3. Нажмите Новая плашечная краска.

    Имена в пределах рисунка уникальны.

    Использование плашечных красок#

    Список Плашечные краски показывает каждую краску с образцом, её имя и кнопки Заливка и Абрис, которые применяют её к выделенному с заданным Тон (от 0 до 100%, по умолчанию 100%). Крестик в конце строки удаляет краску из списка; объекты, которые её используют, сохраняют цвет замены.

    Цветовые справочники#

    Файл палитры может быть справочником плашечных красок (например, палитра .ase с плашечными записями). Её плашечные записи открываются как плашечные цвета с именами из справочника; применение одной из них добавляет краску в рисунок. TraceDraw не поставляется с лицензионными цветовыми справочниками, но имеющийся у вас справочник открывается как любая палитра.

    Плашечные цвета при печати и экспорте#

    • В файлах PDF каждая краска становится цветом цветоделения с её именем, поэтому типография получает краску.
    • При печати цветоделения каждая краска получает свою форму после форм голубой, пурпурной, жёлтой и чёрной. См. Печать.
    • На экране и в растровых файлах, SVG и .cdr плашечный цвет показывается как его замена с его оттенком.
