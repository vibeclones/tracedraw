    Scripts y automatización

    Los scripts automatizan el trabajo repetitivo: dibujar formas a partir de datos, cambiar muchos objetos a la vez o añadir un formato de archivo. Se escriben en JavaScript en el panel Scripts (Herramientas > Scripts > Panel de scripts).

    Escribir y ejecutar scripts#

    Un script trabaja con los objetos de TraceDraw: Application, ActiveDocument, ActivePage, ActiveLayer y las formas, rellenos, contornos, colores, curvas y efectos. Por ejemplo:

    for (let i = 0; i < 5; i++) {
  ActiveLayer.CreateRectangle(10 + i * 25, 10, 20, 20);
}
    • Ejecutar ejecuta el script. Sus cambios son un solo paso de deshacer.
    • Grabar graba lo que hace como un script (también Herramientas > Scripts > Grabar macro).
    • Cargar y Guardar abren y guardan scripts; Ejecutar script ejecuta un archivo de script.
    • Borrar vacía el editor; la Salida muestra lo que imprime el script y sus errores.

    Depuración#

    En la versión de escritorio, haga clic en el margen del editor para poner un punto de interrupción y luego haga clic en Depurar. El script se detiene en el punto de interrupción: puede Continuar, Avanzar un paso o Detener, y escribir una expresión para evaluarla donde está en pausa el script.

    Filtros de script#

    Un script que define TraceDrawFilter, con un nombre, unas extensiones y una función Import o Export, añade un formato de archivo a Importar y Exportar. Haga clic en Instalar como filtro para conservarlo; Filtros de script enumera los filtros instalados con Editar y Quitar.

    Asistentes de IA (MCP)#

    TraceDraw habla el Model Context Protocol, de modo que los asistentes de IA de su equipo pueden abrir, editar, inspeccionar, exportar y guardar dibujos:

    • tracedraw --mcp ejecuta TraceDraw sin ventana para un asistente.
    • Para que un asistente edite el dibujo abierto en su ventana, active Permitir que agentes de IA de este equipo editen el dibujo abierto (MCP) en la página General de Herramientas > Opciones > Global, y dé al asistente tracedraw --mcp-window como comando. Cada cambio es un paso de deshacer que puede revertir. Solo pueden conectarse los programas de su equipo que tengan el token secreto que escribe TraceDraw.

    La herramienta de línea de comandos#

    Cada descarga incluye también tracedraw-cli, que convierte dibujos entre formatos sin abrir el programa, para trabajos por lotes.

    Macros#

    TraceDraw ejecuta proyectos de macros VBA escritos para programas de dibujo (versión de escritorio). Herramientas > Macros > Cargar proyecto de macros añade un proyecto (.gms) o archivos de módulo (.bas, .cls, .frm); los proyectos se guardan y se cargan al iniciar. El Administrador de macros muestra sus macros: haga doble clic en una o use Herramientas > Macros > Ejecutar macro (Alt+Shift+F8) para ejecutarla. Los formularios y cuadros de mensaje y de entrada de la macro aparecen en pantalla, Esc o Herramientas > Macros > Detener macro la detiene, y todo lo que cambia una ejecución es un solo paso de deshacer. Herramientas > Macros > Editor de macros (Alt+F11) muestra y edita el código. Las macros que llaman funciones de Windows o al modelo de objetos del propio editor no se ejecutan.
