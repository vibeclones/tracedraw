    Placing objects inside a frame

    A clip frame is a closed object that holds other objects and shows only the parts of them that lie inside it, like a picture in a window. The frame keeps its own fill and outline; the objects inside stay whole and can be taken out again. The commands are in Object > Clip to Frame.

    To place objects inside a frame#

    1. Select the objects to place inside.
    2. Choose Object > Clip to Frame > Place Inside Frame.
    3. Click the closed object that will be the frame.

    The objects keep their position. You can also drag the objects onto the frame with the right mouse button and choose to place them inside; see Dragging with the right button.

    Editing what is inside#

    • Edit Contents enters the frame: only the objects inside can be edited, the rest of the page is dimmed and the frame shows as an outline. Finish Editing Contents, or the button on the property bar, leaves it.
    • Extract Contents makes the objects inside ordinary objects again; the frame stays, empty.
    • Lock Contents to Frame (on at first): moving, scaling or rotating the frame takes the contents along. Turned off, the frame moves alone and the contents stay where they are on the page.

    Double-clicking a frame with the Pick tool also enters it; see Focus mode.

    Opacity masks#

    Object > Clip to Frame > Opacity Mask turns the selected clip frames into opacity masks: the frame is no longer drawn, and its brightness decides how much of the contents shows: fully where it is white, not at all where it is black, and nothing outside the frame. Fill the frame with a gradient for a soft fade. Invert Mask swaps that, so black shows. Choose the command again to turn the mask back into a plain frame.

    Empty frames#

    Right-click an object and use its frame type commands:

    • Create empty clip frame turns each selected object into an empty clip frame, ready to hold objects.
    • No frame turns an empty clip frame back into the object it was.
    • Create empty text frame replaces the object by an empty paragraph text frame of its size, ready for the Text tool.

    Cropping a bitmap with the Crop tool or the Shape tool also places it in a clip frame; see Cropping, cutting and erasing.
