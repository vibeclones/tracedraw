    Commandes des menus

    Cette page liste les commandes de chaque menu, dans l'ordre du menu, avec la page qui explique chacune. Les commandes qui demandent un dessin sont grisées tant que seul l'écran d'accueil est ouvert. Les menus peuvent afficher vos propres raccourcis ; voir Options de personnalisation.
