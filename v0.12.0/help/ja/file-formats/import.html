    Importing files

    File > Import (Ctrl+I) adds the content of a file to the drawing that is open, on the active layer, as one undo step. Open instead opens a file as a drawing of its own. Both read the formats listed in Supported file formats.

    Where imported objects go#

    At first, imported objects go where the file has them. To center them in the view instead, change the setting on the File Formats page of the global options; see Global options.

    Notes on some formats#

    • PDF and AI: the Import PDF dialog box asks how to read the text: as editable text, which keeps its fonts when they are installed, or as curves, drawn from the fonts the file embeds so the text looks exactly as it does in the file. Options > File Formats keeps the choice. A protected file asks for its password in the Protected PDF dialog box.
    • EPS and PostScript: each printed page becomes a page.
    • PSD: each layer becomes a bitmap with its opacity, visibility and mask.
    • DXF: drawing units are taken from the file.
    • Text files (TXT, RTF, DOCX): become paragraph text, with bold, italic, sizes and fonts where the file has them.
    • Bitmaps: placed at their resolution; see Bitmaps.

    When some objects of a file cannot be read, or fonts are missing, a message says so; see Notes after opening. You can also drag files onto the window, or paste from other programs; see Paste Special.
