    Pomoc programu TraceDraw/Informacje/Keyboard shortcuts

    Ta strona nie jest jeszcze przetłumaczona i jest wyświetlana po angielsku.

    Keyboard shortcuts

    These are the shortcuts TraceDraw comes with. The menus show each command's shortcut beside it, and you can add your own; see Customization options. On macOS, Ctrl is the Command key.

    Help#

    KeysAction
    F1the Help page of the open dialog box, else of the panel on show, else of the active tool

    Files and editing#

    KeysAction
    Ctrl+N, Ctrl+Onew drawing, open
    Ctrl+S, Ctrl+Shift+Ssave, save as
    Ctrl+I, Ctrl+E, Ctrl+Pimport, export, print
    Ctrl+F4, Alt+F4close the drawing, exit
    Ctrl+Z, Ctrl+Shift+Z, Ctrl+Rundo, redo, repeat
    Ctrl+X, Ctrl+C, Ctrl+V, Ctrl+Shift+Vcut, copy, paste, paste in view
    Ctrl+D, Ctrl+Shift+Dduplicate, Step and Repeat panel
    +duplicate the selection in place
    Ctrl+A, Deleteselect all, delete
    Ctrl+0 to Ctrl+9, 0 to 9, Alt+0 to Alt+9store, select (twice: zoom to) and add to selection groups
    Ctrl+F, Ctrl+J, Ctrl+WFind and Replace panel, options, refresh the window

    View#

    KeysAction
    F2, Shift+F2, F3Zoom tool, zoom to the selection, zoom out
    F4, Shift+F4zoom to fit, zoom to the page
    Ctrl++, Ctrl+-zoom in and out one step
    Alt+Shift+Rrulers on and off
    Alt+Q, Alt+Z, Ctrl+Ysnapping off, snap to objects, snap to the grid
    Alt+Shift+A, Alt+Shift+Dalignment guides, dynamic guides
    PgUp, PgDnprevious and next page

    Objects#

    KeysAction
    Ctrl+G, Ctrl+Ugroup, ungroup
    Ctrl+L, Ctrl+Kcombine, break apart
    Ctrl+Q, Ctrl+Shift+Qconvert to curves, convert outline to object
    Ctrl+Home, Ctrl+Endto front and back of the page
    Shift+PgUp, Shift+PgDnto front and back of the layer
    Ctrl+PgUp, Ctrl+PgDnforward one, back one
    L, R, T, B, E, C, Pwith a selection: align left, right, top, bottom, centers horizontally, centers vertically, center to page
    Arrow keys, with Shift or Ctrlnudge, super nudge, micro nudge
    Alt+S, Alt+E, Alt+Shift+E, Alt+Shift+S, Alt+Xcreate, edit, finish, remove symmetry, break its link
    Ctrl+Mmerge table cells

    Panels#

    KeysPanel
    Alt+EnterProperties
    Ctrl+Shift+AAlign and Distribute
    Alt+F7, Alt+F8, Alt+F9, Alt+F10Transformations: position, rotate, scale and mirror, size
    Ctrl+T, Ctrl+F11Text, Glyphs
    F11, Shift+F11fill (Properties), Color
    F12, Shift+F12outline (Properties), outline color
    Ctrl+F7, Ctrl+F8, Ctrl+F9, Ctrl+F10Envelope, Blend, Contour, Extrude
    Alt+F3, Ctrl+F3Lens, Symbols

    Pressing a panel's shortcut when its panel is in front hides the panels.

    Text#

    KeysAction
    F8Text tool
    Ctrl+Shift+Tedit text
    Alt+F12align to baseline
    Ctrl+B, Ctrl+I, Ctrl+Ubold, italic, underline (while editing)
    Ctrl+8, Ctrl+2larger and smaller text
    Ctrl+F12spell check

    Tools#

    KeyTool
    SpacePick (from most tools)
    F10Shape
    F5, F6, F7Freehand, Rectangle, Ellipse
    Z, HZoom, Pan
    Y, A, DPolygon, Spiral, Graph Paper
    G, MInteractive Fill, Mesh Fill
    XEraser
    W, V, ESmear, Smudge, Roughen
    S, Shift+S, ISketch, Shape Recognition, Brush Strokes

    The Toolbox page lists every tool. Each tool has its own keys while you use it, explained on its page; for the Shape tool, see Shaping curves.

    Dialog boxes#

    Enter presses OK and Esc closes a dialog box without applying it. While a dialog box is open, the shortcuts above are not used, except F1.
