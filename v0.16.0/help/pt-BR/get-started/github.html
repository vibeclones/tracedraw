    Guardar desenhos no GitHub

    O TraceDraw pode abrir desenhos de um repositório do GitHub e salvá-los de volta como commits, no computador e no navegador. Cada salvamento vira uma versão no histórico do repositório, que você pode abrir de novo depois. Os comandos ficam em Arquivo > GitHub.

    Antes de começar: o token#

    Repositórios públicos abrem sem token. Para abrir os privados e para salvar, crie no GitHub um token de acesso pessoal refinado com acesso de leitura e escrita ao conteúdo do repositório, e cole-o no campo Token.

    O token fica guardado enquanto o TraceDraw está aberto. Marque Lembrar o token neste computador para mantê-lo para a próxima vez; ele é então guardado em texto simples nas suas preferências (no navegador, no armazenamento daquele navegador). As caixas de diálogo também lembram o último repositório, branch e caminho.

    Abrir um desenho do GitHub#

    1. Escolha Arquivo > GitHub > Abrir do GitHub.
    2. Digite o Repositório como dono/nome ou o endereço dele no github.com.
    3. Digite a Branch, ou deixe em branco para main.
    4. Digite o caminho do Arquivo no repositório, por exemplo art/logo.tdraw.
    5. Clique em OK.

    O desenho abre em uma nova guia, com o nome do arquivo. Ele lembra de onde veio e qual versão era.

    Salvar um desenho no GitHub#

    Para um desenho aberto do GitHub, Salvar (Ctrl+S) o salva de volta. Para qualquer desenho, escolha Arquivo > GitHub > Salvar no GitHub.

    1. Confira o repositório, a branch e o caminho.
    2. Escreva uma Mensagem do commit que diga o que mudou (começa com "Update" e o nome do arquivo).
    3. Clique em OK.

    O desenho é salvo como arquivo .tdraw, com as fontes, como um novo commit nessa branch. Salvar como continua salvando um arquivo no seu computador.

    Quando o GitHub recusa um salvamento#

    Se o arquivo mudou no GitHub depois que você o abriu, ou já existe um arquivo naquele caminho e o seu desenho não veio dele, o GitHub recusa o salvamento e a caixa de diálogo avisa. Salve em outro caminho ou branch, ou abra a versão mais nova primeiro. A caixa de diálogo também explica outros problemas: um token recusado ou sem acesso, pedidos demais, um repositório, branch ou arquivo que não existe, um caminho que é uma pasta, um arquivo que não é um desenho, ou um desenho com mais de 100 MB.

    Abrir uma versão anterior#

    Para um desenho aberto do GitHub, escolha Arquivo > GitHub > Histórico. A caixa lista os commits que mudaram o arquivo, do mais novo ao mais antigo, com id curto, data, autor e mensagem. Selecione um e clique em Abrir: essa versão abre como um novo desenho, com o nome do arquivo e do commit, que não fica ligado ao GitHub.
