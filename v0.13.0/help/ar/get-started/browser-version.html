    تعليمات TraceDraw/البدء/The browser version

    لم تُترجم هذه الصفحة بعد وتُعرض بالإنجليزية.

    The browser version

    You can use TraceDraw in a web browser with nothing to install. It is the same program as the desktop version, built for the browser, so the menus, tools and files are the same.

    The message at start#

    Each time the page opens, a message explains that the browser version is the same program as the desktop one, and what differs. OK (or Enter) closes it; a second button opens the downloads of the desktop version.

    What differs from the desktop#

    • Speed. Large drawings, heavy effects, tracing, mosaics and big exports are slower, and keep the page busy until they finish. The desktop version runs at full speed.
    • Files. Opening and importing use the browser's file picker; saving, exporting and printing download a file. Recent drawings are not listed, because a browser cannot reopen an uploaded file.
    • Fonts. The page brings its own fonts and fetches more the first time your text needs them.
    • Settings are kept in that browser on that computer.
    • Keys. While the drawing has the focus, the program's shortcuts reach TraceDraw instead of the browser, except the clipboard keys, reload and the browser's developer tools. Ctrl+N, Ctrl+T and Ctrl+W always stay with the browser, so use the File menu to create and close drawings.
    • Screens. It suits a desktop browser with a mouse and keyboard. On a tablet, use the Touch workspace (see Workspaces); a phone screen is too small for editing.
    • Updates. The browser version is always the latest; there is nothing to install. Auto-backup and session recovery are desktop features.
